# コード帖 — v1

コードの名前から「鍵盤のどの音を押すか」を見て、メトロノームに合わせてコード進行を練習するアプリです。
楽譜が読めなくても、コード譜（C や Am などの記号）を見て弾けるようになるための道具です。

## できること

### 1. コード（辞典）
- ルート12種類 × 種類7つ（メジャー／m／7／M7／m7／sus4／dim）＝84コードの構成音を、鍵盤の絵とカタカナ（ド・ミ・ソ）で表示
- オレンジ＝ルート（いちばん左の音）、青＝ほかの音
- 「いっしょに鳴らす」「1音ずつ」で音を確認。鍵盤をタップするとその音が鳴る
- 3和音には指の目安、4和音には「まず3つだけ弾いてもOK」の案内を表示

### 2. れんしゅう
- コード進行を選び、メトロノームに合わせて練習（スタート後、1小節カウントしてから開始）
- テンポ 40〜140、1コードあたり 4拍／2拍
- 「お手本の音」：各コードの頭で和音を鳴らす
- 「鍵盤を隠す」：鍵盤とカタカナを隠し、コード名だけで思い出して弾く練習
- 「自分で作る」：好きな曲のコード譜を見ながら、並びどおりにコードを追加（最大16個、この端末に保存）
- 練習中は画面が消えないようにします（対応している端末のみ）
- iPhoneで音が出ないときは、側面の消音スイッチ（マナーモード）を確認してください。このアプリは、マナーモード中でも鳴らす設定を入れていますが、端末のバージョンによっては効かない場合があります

### 3. しくみ
音の数え方（メジャー＝0・4・7、マイナー＝0・3・7）、7th、sus4・dim、「C/E」の読み方など

## 進行の出典（2026/11/26に確認）
| 名前 | コード（Cのキー） | 確認元 |
|---|---|---|
| Let It Be（Aメロ） | C G Am F / C G F C | Pianote（Let It Be Piano Chords & Tutorial） |
| Stand By Me | C Am F G | 複数のコード譜サイト（原曲はAのキー。楽譜ではCで書かれることが多い） |
| 4コード | C G Am F | ragnet「レット・イット・ビー進行（1564進行）」 |
| 王道進行 | F G Em Am（7thつき：FM7 G7 Em7 Am） | Wikipedia「Royal road progression」 |
| カノン進行 | C G Am Em F C F G | UtaTen、ragnet |

曲名は「その進行が使われている例」で、歌詞・楽譜は含みません。実際の曲は、版やアレンジによって細部（7thの有無など）が異なります。

## 未対応
- 「C/E」のような分数コード（いちばん下の音の指定）。最初は無視してCとして弾いてOK
- キー（移調）の切り替え。進行のプリセットはCのキーのみ（「自分で作る」なら任意のコードを入れられます）
- m7♭5、add9、aug などの種類

## ファイル構成（すべて同じ階層。サブフォルダは作らない）
```
index.html             アプリ本体（単一HTML・外部依存なし）
manifest.json          PWA設定
sw.js                  Service Worker（CACHE = chordcho-v1）
apple-touch-icon.png   180×180（iPhone/iPadのホーム画面用）
icon-192.png
icon-512.png
icon-maskable-512.png  余白付き（Android用）
README.md
```
サブフォルダを作らないのは、GitHubのWeb画面（特にiPhone）からアップロードするとフォルダ階層が消え、アイコンのパスがずれて表示されなくなるためです。

## 公開手順（GitHub Pages）
1. GitHubで新しいリポジトリ（例：`Chord`）を作る
2. ZIPを展開し、**8ファイルすべて**をリポジトリ直下にアップロード（Add file → Upload files）
3. Settings → Pages → Branch を `main` / `/ (root)` にして Save
4. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` で開ける
5. iPhoneはSafariで開き、共有 → ホーム画面に追加

## アイコンが反映されないとき
1. `https://<ユーザー名>.github.io/<リポジトリ名>/apple-touch-icon.png` を開いて絵が出るか確認
2. ホーム画面のアイコンは追加した時点の画像で固定されます。ホーム画面から削除し、Safariで開き直して再追加
3. それでも古ければ、Safariのアドレスバー左の「ぁあ」→「Webサイトの設定」などから、このアプリのページだけを開き直す

> ⚠ 「設定 → Safari → 詳細 → Webサイトデータ」から **github.io を削除する手順は使わないでください**。github.io は、同じアカウントの他の自作アプリ（家計簿・株帳など）と同じ場所（オリジン）を共有しているため、それらの保存データまで消えます。

## 更新するとき
全ファイルを上書きしてください。`sw.js` の `CACHE` は、更新のたびに `chordcho-v2`、`v3` … と上げてください（上げないと古い画面が残ります）。

## 保存されるデータとプライバシー
- 保存先は端末の localStorage（キー名 `chordcho-v1`）だけです。内容は、テンポ・拍数・選んだ進行・「自分で作る」のコード並びのみ
- 外部への通信、アカウント、APIキーはありません（CSPで接続先を自分自身に限定）
- 公開リポジトリにすると、アプリのコードは誰でも見られます（個人情報は含まれていません）

## 技術メモ
- メトロノームは `AudioContext.currentTime` を基準にした先読みスケジューラ（25ms間隔・120ms先読み）。実測で、コード切替の間隔は理想値±10ms以内
- 音名のつづりは、理論どおりに数えたうえで、C♭・F♭・E♯・B♯・ダブル♯♭ になる場合だけ読みやすい別名（B・E・F・C など）にしています（例：B♭dim ＝ シ♭・レ♭・ミ。理論上は「ファ♭」ですが、読みやすいように「ミ」と表示）
- 黒鍵のルートは、メジャー系は D♭・E♭・A♭・B♭・F♯、マイナー系は C♯・E♭・G♯・B♭・F♯ を主に表示し、「別の書き方」も併記
